# Keshav Buddy — RAG Helpdesk Chatbot for Keshav Mahavidyalaya (University of Delhi)

A Retrieval Augmented Generation (RAG) chatbot for the college site helpdesk of
**Keshav Mahavidyalaya, University of Delhi**. It answers questions about admissions,
courses, fees, placements, facilities, scholarships and contact details, grounded in a
local knowledge base.

## Features

- **Free, open-source, local LLM**: answers are generated by `qwen2.5:3b` served through
  [Ollama](https://ollama.com). No paid API keys required.
- **Vector embeddings**: questions and knowledge-base chunks are embedded with the free
  `nomic-embed-text` model via Ollama.
- **Semantic retrieval**: a lightweight numpy cosine-similarity vector store fetches the most
  relevant chunks (no external vector DB needed).
- **Grounded answers**: the model is instructed to answer only from retrieved context and to
  defer to the college office when it does not know.
- **Suggested questions / FAQ**: one-click FAQ chips in the UI powered by `/api/faqs`.
- **Streaming responses**: tokens stream to the browser via Server-Sent Events.
- **Source citations**: each answer shows which knowledge-base sections it used.

## Architecture

```
Browser (static/)  ──HTTP/SSE──►  Flask (app.py)
                                      │
                                      ▼
                                 RAGEngine (rag.py)
                                   │        │
                        embed query      retrieve top-k
                                   │        │
                                   ▼        ▼
                         Ollama embeddings  numpy VectorStore (embeddings.py)
                         (nomic-embed-text)  ◄── built by ingest.py
                                   │
                                   ▼
                          Ollama chat (qwen2.5:3b) ──► answer + sources
```

## Prerequisites

1. **Python 3.10+**
2. **Ollama** installed and running (`ollama serve` runs automatically after install).
3. Pull the free models once:

   ```powershell
   ollama pull qwen2.5:3b
   ollama pull nomic-embed-text
   ```

## Setup

```powershell
cd "E:\Github\AI Bot"
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Build the vector index

```powershell
.\.venv\Scripts\python.exe ingest.py
```

This reads every file in `knowledge_base/`, chunks it, embeds it and writes
`data/vector_index.npz`.

## Run the web app

```powershell
.\.venv\Scripts\python.exe app.py
```

Then open <http://localhost:5000>. On Windows you can also just double-click `run.bat`.

## API

| Method | Endpoint            | Description                                        |
|--------|---------------------|----------------------------------------------------|
| GET    | `/api/health`       | Service status and active model names              |
| GET    | `/api/faqs`         | Suggested questions / FAQ list                     |
| POST   | `/api/chat`         | `{"question": "..."}` → `{answer, sources}`        |
| POST   | `/api/chat/stream`  | SSE stream of `sources`, `token`, `done` events    |

Example:

```powershell
curl.exe -X POST http://localhost:5000/api/chat -H "Content-Type: application/json" -d "{\"question\":\"What is the fee for B.Com Hons?\"}"
```

## Updating the knowledge base

Edit or add Markdown/text files in `knowledge_base/`, then re-run `ingest.py`
(or POST any message after deleting `data/vector_index.npz` — the engine rebuilds automatically).
You can also force a rebuild from Python with `RAGEngine().reload()`.

## Configuration

All tunables live in `config.py`: model names, Ollama host, chunk size/overlap, `TOP_K`,
minimum similarity score and the system prompt.

## Notes

- This is an independent helpdesk assistant. Always verify critical information (fees, dates,
  cut-offs) on the official site <https://keshav.du.ac.in>.
- The knowledge base reflects publicly available information collected for demonstration.
